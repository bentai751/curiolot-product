# CURIOLOT

**A collectible-auction platform being developed for Hong Kong.**

CURIOLOT is a product of **Cultivata Services Limited（培賢有限公司）**, Hong Kong.

## Product

We are building software to help collectors discover auction listings, follow bidding activity and understand transaction progress. Categories include models, art toys, cards and other collectibles.

The product is in development and testing. The full auction platform has not launched publicly, and payment and transaction flows are still being validated.

## Interactive demonstration

This repository contains a standalone, browser-based product demonstration in [`docs/`](docs/). It supports category filtering, listing search, collectible selection, simulated bid validation and resetting the demonstration.

All listings, illustrations, prices and bid records are synthetic. The demonstration does not process payments, operate real auctions or connect to customer data. Bids exist only in the current page's memory and disappear on reload.

- [Traditional Chinese product page and interactive demo](docs/index.html)
- [English product overview](docs/product.html)

**Public product website and demo: [about.curiolot.online](https://about.curiolot.online/).**

Download this repository and serve `docs/` with a local static web server to run the demo. Opening HTML directly from disk may block JavaScript modules.

The product application remains private. This repository contains only this public demonstration and product information, not the full platform source.
